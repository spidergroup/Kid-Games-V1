# Tasks for Playful Wonders Website

## Frontend Development

### General
- [ ] Create a responsive layout for the main website.
- [ ] Design a bright and colorful UI suitable for children.
- [ ] Ensure the website is accessible (WCAG compliant).
- [ ] Implement a navigation menu to switch between games.

### Game Development

#### Star Catchers
- [ ] Develop the game logic for falling stars.
- [ ] Implement player controls (character/basket movement).
- [ ] Add a scoring system.
- [ ] Create animations for catching stars.

#### Matching Game
- [ ] Create the game board with a grid of cards.
- [ ] Implement card flipping animation.
- [ ] Develop logic for matching pairs.
- [ ] Add a timer or move counter.

#### Three Card Monte
- [ ] Implement the card shuffling animation.
- [ ] Develop logic for tracking the correct card.
- [ ] Add feedback for correct/incorrect guesses.

#### Hangman Game
- [ ] Create the UI for the hangman drawing and the word.
- [ ] Implement the logic for guessing letters.
- [ ] Add a word bank for the game.
- [ ] Draw the hangman for incorrect guesses.

## Backend Development (Optional)

- [ ] Set up a backend to store high scores (if desired).
- [ ] Create an API to fetch words for the Hangman game (if desired).

## Testing

- [ ] Test the website on different devices and browsers.
